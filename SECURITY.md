# Security Policy

## Reporting a vulnerability

Email **hr@bravehaven.io** with "Security" in the subject line. Please do not open a public issue.

Include what you found, how to reproduce it, and the impact you expect. You will get an acknowledgement within three business days and a plan for a fix after triage.

The GitHub profile README for Younique98. It has no application code and stores no personal data. Every push is scanned for secrets, the workflows are statically analyzed, and every GitHub Action is pinned to a commit SHA.
